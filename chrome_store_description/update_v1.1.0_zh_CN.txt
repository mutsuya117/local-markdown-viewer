【1.1.0 版本更新内容】

■ YAML Front Matter 格式化显示（新功能）
· 将文件开头由“---”包围的 YAML Front Matter 以 GitHub 风格的元数据表格清晰展示。
· 支持标量、列表以及嵌套映射。
· 采用严格的识别逻辑以防止误判，不会破坏水平分隔线或标题中的“---”。
· 实时预览与导出的 HTML 均已支持。

■ 制表符表格错位修复（改进）
· 修复了代码块中使用制表符（─│┌ 等）绘制的表格在包含中文、日文等 CJK 字符时发生错位的问题。
· 通过优先使用操作系统自带的 CJK 等宽字体，使半角与全角字符保持精确的 1:2 宽度比例，从而让框线整齐对齐（无需内置或下载字体，不增加扩展体积）。
· 根据界面语言自动切换日文／简体中文／繁体中文的字体优先级。

■ 内置库更新（维护）
· 更新至 DOMPurify 3.4.8 / Mermaid 11.15.0 / KaTeX 0.16.47，提升安全性与稳定性。

感谢您使用 Local Markdown Viewer，欢迎提出您的意见和功能建议。

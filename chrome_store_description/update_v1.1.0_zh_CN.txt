【1.1.0 版本更新内容】

■ YAML Front Matter 格式化显示（新功能）
· 将文件开头由“---”包围的 YAML Front Matter 以 GitHub 风格的元数据表格清晰展示。
· 支持标量、列表以及嵌套映射。
· 采用严格的识别逻辑以防止误判，不会破坏水平分隔线或标题中的“---”。
· 实时预览与导出的 HTML 均已支持。

■ 支持 .mkdn 扩展名（新功能）
· 除 .md / .markdown 外，现在也可预览 .mkdn 扩展名的 Markdown 文件。

■ 修复非 ASCII 文件名乱码问题（缺陷修复）
· 修复了当文件名包含日文、中文、表情符号等非 ASCII（多字节）字符时，HTML 导出、打印及页面标题出现乱码的问题。

■ 内置库更新（维护）
· 更新至 DOMPurify 3.4.8 / Mermaid 11.15.0 / KaTeX 0.16.47，提升安全性与稳定性。

感谢您使用 Local Markdown Viewer，欢迎提出您的意见和功能建议。

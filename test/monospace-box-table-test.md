# 等幅フォント・罫線テーブルのテスト

Issue #4 の対応確認用テストファイルです。
コードブロック内で罫線（box-drawing characters）を使ったテーブルが、
日本語・英語・中国語が混在していてもずれずに表示されることを確認します。

## 1. 日本語を含む罫線テーブル

```text
┌──────────┬──────────┬──────────┐
│ 名前     │ 年齢     │ 職業     │
├──────────┼──────────┼──────────┤
│ 田中     │ 28       │ 技術者   │
│ 佐藤     │ 35       │ 設計者   │
│ 鈴木     │ 42       │ 管理者   │
└──────────┴──────────┴──────────┘
```

## 2. 英数字のみの罫線テーブル

```text
+----------+----------+----------+
| Name     | Age      | Role     |
+----------+----------+----------+
| Tanaka   | 28       | Engineer |
| Sato     | 35       | Designer |
| Suzuki   | 42       | Manager  |
+----------+----------+----------+
```

## 3. 中国語を含む罫線テーブル

```text
┌──────────┬──────────┐
│ 名称     │ 数量     │
├──────────┼──────────┤
│ 苹果     │ 10       │
│ 香蕉     │ 25       │
└──────────┴──────────┘
```

## 4. 日英混在の罫線テーブル

```text
╔══════════╦══════════╗
║ 項目Item ║ 値Value  ║
╠══════════╬══════════╣
║ CPU使用  ║ 45%      ║
║ MEM使用  ║ 60%      ║
╚══════════╩══════════╝
```

## 5. ツリー表示（罫線）

```text
プロジェクト/
├── src/
│   ├── main.js
│   └── utils.js
├── test/
│   └── test.js
└── README.md
```

## 確認ポイント

- 各セルの縦罫線（`│` `║` `|`）が縦方向に揃っていること
- 日本語・中国語などの全角文字を含む行でも罫線が崩れないこと
- ライトモード／ダークモードの両方で正しく表示されること
- HTMLエクスポート後も同様に揃っていること
